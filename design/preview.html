Palette

Two accents carry the whole system. Ember is HauntedReal reporting — lantern light, not blood. Spectral is community-submitted experience — cold, other, never confused with editorial. Body text sits at 16.4:1 against the ground; the muted tone still clears 8:1. Nothing on this site is dark grey on black.

  • Void#08090cPage ground
  • Surface#0e1015Cards, masthead
  • Raised#141822Hover, panels
  • Text#ecebe8Body copy — 16.4:1
  • Muted#a8adb8Meta, captions — 8.1:1
  • Ember#e5903aEditorial accent
  • Spectral#8fb9d4Community accent

Type scale

A serif display face for credibility, a system sans for body speed — no webfont request, no render-blocking CDN, no invisible-text flash. Sizes are clamp() values, so type scales continuously instead of jumping at breakpoints. Swap --hr-font-display in one place to introduce a licensed face later.

Advertising slots

No network code is ever written into a template. Each slot fires a named action and resolves its markup in inc/ads.php, so Adsterra can be replaced from the Customizer without touching a template file. Every slot reserves its height before anything loads — the reserved column below is the CLS budget.

Breakpoints

Mobile is the base layer, not a shrunken desktop: the small-screen rules are what the stylesheet opens with, and each breakpoint only adds. The sidebar advertisement is never forced onto a phone — it is not in the markup below 1024px.

RangeWidthWhat changes
Mobile320–767pxSingle column · hamburger drawer · 56px header · no sidebar
